# Stock A 实现详细设计

## 1. 范围

本文只描述现役仓库中已找到的CLI、API、PG读取实现及其真实业务消费者。产品目标仍为全市场画像、市场→板块→个股、变化识别和持续跟踪；本文不把尚未接通的目标写成已实现能力。金融公式、窗口、单位、坐标和质量规则以 [算法合同与升级规则](算法合同与升级规则.md) 为准。

## 2. 现役架构

业务入口在 src/stock_a/application；PG适配在 storage/postgres；HTTP路由和固定资源服务在 service；领域函数位于 canonical、research、sources等单一业务包；页面资源独立位于 web/preview。配置从config/runtime.defaults.json和登记的合同资源读取。

当前价格字段机器合同为config/contracts/price-profile.contract.json，拆成来源字段、Core字段、Profile字段三个受摘要验证的模块，只登记运行时实际消费的价格语义。

来源路径由现有CLI读取授权源、检查输入和解析Raw，按精确日期、来源代码、package_sha256及source_capture_id写入stock.source_raw_daily。source_contents和source_captures用于解释内容摘要与本机采集时钟。原始来源根保持只读。

Core根据明确目标日及实际可用历史Bars计算。Profile组合现役Core字段并将可持久化画像写入stock.source_symbol_price_profiles。当前表的主键和外键仍含历史source_set_id/source_set_revision列，因此画像存储保留该数据库键；价格关系API由日期、包SHA和画像revision解析唯一画像行。Raw研究按来源事实直接读取。

## 3. CLI现状

唯一正式入口由stock-a与python -m stock_a共享，详细命令参数以当前 --help 和 parser_registration 为准。研究命令有显式日期/截止、来源代码、包SHA或本机授权路径参数。生产命令不可从本地步骤推断或自动触发。

已有研究消费者包括：
- source-raw读取精确Raw日线和捕获/内容事实；
- research-stock单股指标、周期和变化解释；
- research-universe-preview来源候选检查；
- D0 Raw新增/变化观察、D1突破回踩和市场/板块Raw计算；
- 从PG读取已保存的精确Profile，用于趋势关系和两日期变化。

新入参以日期、包SHA和Profile修订选择画像。现存数据库主键仍含历史来源ID；存量画像读取在数据库层按业务版本解析行键，缺失或不唯一时返回具体错误。

## 4. PG事实与消费者

| 关系/数据 | 当前用途 | 处理 |
|---|---|---|
| stock.source_raw_daily | Raw读取、单股、D0/D1、宽度和成员研究 | 保留，直接按精确日期、包和来源范围读取 |
| stock.source_contents / source_captures | 输入内容和实际捕获时钟 | 保留作来源事实 |
| stock.source_symbol_price_profiles | Profile11及两日期筛查/变化 | 保留已保存画像和现有业务主键 |
| stock.source_sets | Profile历史主键与外键 | 暂保留画像存储所需的现有键；移除前需获PG对象授权并迁移真实画像行 |

PG catalog核对必须只读，并报告当前迁移版本、真实外键、唯一约束和数据日期范围。源集合关系被其他表引用时不伪装已删除；历史迁移文件若已应用，保持校验摘要和迁移顺序不变。实际物理DROP/破坏性ALTER需要具体对象授权。

## 5. API行为

服务只从固定端口127.0.0.1:28766提供开发预览；GET保持只读。产品静态资源只允许static_assets.py列出的路径。页面必须由服务资源白名单实际提供，不依赖来源本地文件直接渲染。

价格画像关系筛查端点为GET /api/source-symbol-price-profile-relation-screen。前后日期、包SHA和画像revision精确绑定；relation_field为必填，transition_type缺省为ALL，offset缺省为0、limit缺省为50。after_amount_ratio20_min与after_volume_ratio20_min同时出现时按AND筛选。total_count为完整匹配数，offset/limit控制真实分页；非法参数返回4xx和中文原因。

单股Raw/Core预览、75会话轨迹、周/月周期、市场来源分页、两日关系和D0变化入口分别沿用自身实际消费者。Raw日期与package SHA不可由后台latest替换。Source_launch_watch读取现场计算结果。前后端只传递业务计算参数，不复制算法公式实现。

## 6. UI显示

页面的日期选择器、市场来源分页、单股搜索、历史图表、变化详情及关系筛查直接驱动已接通API。保留用户可见的算法变化和Focus跟踪信息。

浏览器验收只使用Codex内置浏览器，并实际操作日期切换、搜索、分页、展开/折叠等适用功能。必须通过正在运行的本次源码服务观察可见数据和交互。静态DOM或HTTP 200不能代替页面验收。

## 7. 新能力边界

需求中的全市场画像、市场→板块→个股、变化识别、持续跟踪和前瞻验证继续保留。部分实现只按真实CLI/API/PG/UI证据报告其范围。真实历史成员、身份、来源available_at或PIT缺失时，只将依赖这些证据的字段标UNKNOWN或NON_PIT，不妨碍可独立计算的价格画像。
