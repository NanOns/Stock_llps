# 正式需求与设计变更

本文件只登记现行设计决策。被取代的历史方案可从Git历史查阅，不作为当前执行规则。产品需求和算法公式分别由产品需求.md、PROJECT_SPEC.md及算法合同与升级规则.md维护。

## CHG-016：保留的金融研究公式与状态语义

继续采用现行算法合同中明确列出的三窗口、RPS中秩、金额比率分母、市场宽度主式、Core/Supplemental隔离、板块与LOO、Rotation、D0/D1/D2、Focus顺序及变化语义。来源单位、坐标、质量、时间角色和未知状态不得被工程改造改写。公式变更须有独立正常、边界和错误向量；本决策不表示其所有消费者已实现或真实数据已验证。

## CHG-055：删除式架构减负

现行数据路径为来源读取→Raw PG→Core/Profile→具体研究消费者→CLI/API/页面。源码、页面和机器合同只保留可追到真实消费者的内容。已应用迁移原文件不改写；账本可经前向迁移保留原迁移编号、应用时点与lineage并删除迁移源码SHA。无消费者控制表和存量业务键按真实引用及数据映射前向清理。

实际捕获时钟、Raw质量、金融算法事件和用户持续跟踪按真实消费者保留。来源包SHA仅在TDX原包接收校验入口保存一个package_sha256字段；Profile行使用数字Raw父ID、单列BIGINT IDENTITY主键及显式画像修订。来源集合键、下游SHA及DEV/PROD/TEST namespace不属于现役业务身份。

本决策不撤销136项产品需求，不改变金融数学语义，也不把全市场画像、市场→板块→个股、变化识别或持续跟踪宣称为已全部实现。按实际日期、来源版本和质量逐消费者报告能力。

## CHG-056：静态研究事实先生成并持久化

已有真实消费者的全市场、跨日或历史静态研究结果由离线初始化/日更生产链计算并持久化到有业务键的typed PG事实表；初始化与日更复用同一生产者。服务端默认只读能证明完整的精确日期/来源/算法事实，HTTP不得隐式重算全市场历史。单股下钻、轻量SQL筛选/聚合及小范围比较可即时计算。D0/D1材料在不改现行公式、窗口、坐标和NON_PIT边界的前提下分事实、质量及原因保存。行业/GN当前成员继续使用现有快照JOIN，不复制成员事实。

缺结果、分母不全、零变化和UNKNOWN分别表达；结果生成、typed写入、PG完整读回与真实消费者是分层验收项。必要PG操作的自主判断与执行边界由后续CHG-057统一规定。现役页面应直接读取已完成PG事实并移除HTTP全池重算，不保留双Reader；源码或迁移文件不等于物理应用及消费者验收。

## CHG-057：按业务任务自主判断并执行PG操作

用户决定：Stock A数据库操作由Codex依据当前明确业务任务、真实PG身份与现场数据状态自主判断并执行，无须按SQL种类、表/字段、影响行数或操作类型逐项申请批准。对既存数据的纠错、DDL、DML及必要迁移属于任务范围内操作；执行前核对业务键、来源与修订、匹配数、影响范围和事务恢复路径，执行后以独立事务读回并报告实际结果。该决策取代旧规范中“写入/清理/破坏性操作需具体对象另行授权”的审批门，但不把无关操作纳入任务、不授权生产切换、实例或角色权限改造、Head/调度变更或超出当前目标的旧库处置。PG逻辑身份、单库单schema、集中迁移、来源只读、GET只读及测试合成数据边界继续适用。

## CHG-058：来源级板块PULSE相邻会话变化

行业与GN概念板块只对严格相邻官方会话且同一现存成员快照的完整来源级PULSE事实生成最小typed变化行。业务键通过两端Raw捕获ID、数字来源包ID、Profile显式修订、日历业务版本及板块身份确定；UNKNOWN保留原端点原因，未计算端点保持NOT_COMPUTED。现有板块详情通过现役API读取PG事实；HTTP不重算、不写入。变化仅描述冻结PULSE状态，不修改阈值，也不赋予正式Rotation生命周期状态。

## CHG-059：PG身份字段与来源SHA单入口减负

Stock A自定义SHA-256仅在TDX原始数据包接收校验入口的来源包父记录保存一个package_sha256，用于下载/接收完成后的原件校验；不将SHA或其派生值存入、传入或用于其它来源、Raw/Core/Profile/Seed/D0/D1、市场/板块/PULSE、Cohort/Forward、主外键、缓存、CLI/API/UI或算法上下文。下游使用数字来源包ID、数字捕获ID、实际业务键、显式版本、PG事务及独立Oracle保持幂等和修订差异。

现役业务事实表优先使用单列BIGINT IDENTITY主键，保留必要且短的自然业务唯一键，不以代理ID加原宽唯一键双重建模。DEV/PROD/TEST namespace不用于本项目身份隔离，namespace_id、无消费者的namespace治理表及未实现历史表经生产者、PG依赖和消费者核实后物理删除。无消费者且无保留责任的空表或历史表必须实质DROP；Raw/Core/Profile/Seed/D0/D1/市场/板块/PULSE/Cohort/Forward及其它有用业务事实完整保留。

正常业务事务使用受控`search_path=stock,pg_catalog`及不限定schema的参数化SQL；集中迁移和安装身份等安全敏感核验可显式限定`stock`。迁移账本以连续编号、应用时间和lineage维护有序状态，不依赖迁移源码SHA；已应用原迁移SQL文件及历史应用状态不改写。以上调整只适用于既定单库`stock_a`、单业务schema `stock`，不创建第二数据库、schema、namespace或Runner，不改变研究数值、来源冻结边界或生产运行。

## CHG-060：中文名称作为非PIT显示标签

个股页面以PG中可用的中文`display_name`为主、`source_symbol`为辅；板块标识只显示中文`board_name`，板块原生编号仅用于精确接口与PG查询。本机TDX `.tnf`名称快照仅用于页面标签，保留实际观察时钟，标记`UNVERIFIED_LOCAL_TDX_INSTALLATION`、`NON_PIT_OBSERVED`、`SOURCE_SYMBOL_ONLY_NOT_STABLE_ENTITY`及`source_available_at=NULL`。标签不得充当稳定证券身份、日期有效名称、上市/退市状态或算法字段；不完整、截断或未映射名称显示UNKNOWN，不补写证券名称。PG只保留一个当前标签快照并在单一事务中替换；页面披露捕获时间和非PIT边界。此变更不改变市场、板块、画像、规则或候选计算。

## CHG-061：T0板内相对位置探索性观察

新增解释假设`EARLY_BOARD_RELATIVE_T0_R1`：针对每条已存T0登记，使用精确Raw来源版本和当前TDX行业/GN成员快照展示板块PULSE、严格相邻PULSE事实、同板块RPS5/RPS20并列名次范围、可评价/UNKNOWN分母、RPS5三会话变化、D0/Seed/规则父事实及支持、反证、未知原因和下一步观察条件。多个T0登记及其多个板块关系分别保留，不挑选单一最佳板块，不生成复合评分；HTTP只读离线保存的typed结果。

该假设使用当前成员快照回看并标记`NON_PIT_EXPLORATORY`，不改变D0、Seed、RPS、PULSE、Priority或Focus公式及阈值，不向金融规则反馈。缺失的相邻PULSE或RPS事实分别保持`NOT_COMPUTED`/`UNKNOWN`；未到期后继保持`NOT_DUE`。该功能、数值与页面通过只能证明工程链路可用，不能证明提前发现能力、收益、胜率或因果效果。
