## CHG-017：数据库表/字段注释与项目中文表达

所有正式持久化数据库表和每个字段/列都必须有数据库原生注释，并由集中迁移创建和持续维护；迁移修改字段或其合同含义时同步更新注释。表注释说明业务用途，字段注释说明业务含义，并按适用情况列明单位、值域/枚举、时间角色、质量及空值语义。注释以中文为主，专业词汇、稳定技术标识和固定枚举可保留原生语言，但需有中文释义。缺少表注释或任一字段注释的迁移不得验收。

项目中适合用中文表达的正式规范、说明性源码注释、数据库注释、界面文案、CLI帮助和面向用户的错误/状态信息使用中文。稳定代码标识、协议/配置键、第三方名称、专业词汇和固定枚举值可保留原生语言，以维持技术精确性与兼容性；必要说明用中文提供。该决策落实于AGENTS R8、PROJECT_SPEC R12及工程与存储规范R8，不改变既有数据库身份/拓扑或当前代码与服务状态。
